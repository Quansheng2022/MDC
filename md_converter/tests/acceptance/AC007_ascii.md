# ASCII Diagram

The following ASCII diagram must be converted and rendered:

```ascii
┌─────────┐     ┌─────────┐
│ Client  │────▶│ Server  │
└─────────┘     └─────────┘
```

And a second one:

```diagram
+-------+       +-------+
|  API  |<─────>|  DB   |
+-------+       +-------+
```

Diagram content must not be lost even if rendering falls back to text.

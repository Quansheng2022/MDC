# Nested Lists

## Unordered List

- Level one item
  - Level two item
    - Level three item
- Another level one item

## Ordered List

1. First
2. Second
   1. Nested second item
   2. Another nested second item
3. Third

## Mixed List

- Item A
  1. Sub item 1
  2. Sub item 2
- Item B

Nested list structure and numbering must be preserved.

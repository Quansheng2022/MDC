# WP-P12-10-02 — Release Documentation

**Product Baseline:** `4c02734`

## Objective
Prepare the minimum release documentation needed for RC distribution and P12-11 Human Acceptance.

## Required Scope
Create/update only what is necessary:
- Release Notes
- Known Issues / Accepted Limitations
- Installation Notes
- Uninstall Notes
- Privacy / Local Processing statement
- checksum/artifact manifest
- RC acceptance checklist

Prefer updating authoritative existing documents over creating duplicates.

## Release Notes
Include version, RC scope, major user-visible capabilities, Windows support, local/private/no-subscription positioning, and installer availability. Avoid unverified marketing claims.

## Known Issues
Include only accepted user-relevant limitations. Internal engineering debt belongs in closure evidence, not public notes.

## Acceptance
Documentation accurately describes the frozen RC and creates no new product requirements.

## 使用实例

# 基本转换
md-converter sample.md
md-converter converter1.md --open --verbose

# 指定输出路径并打开
md-converter sample.md --output ./result.docx --open

# 使用配置文件
md-converter sample.md --config config.yaml

# 详细输出
md-converter sample.md --verbose


md-converter input.md --ascii-mode auto          # 默认：自动优选
md-converter input.md --ascii-mode interactive    # 复杂图：交互式选择
md-converter input.md --ascii-mode preview        # 多方案预览（.mmd + 报告）

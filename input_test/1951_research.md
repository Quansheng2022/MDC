# 第十二层：预期价值引擎（Expected Value Engine）

### EV计算

> **EV = (25% × 60.6%) + (50% × 42.2%) + (25% × -17.4%)**
>
> **EV = 15.15% + 21.1% - 4.35% = 31.9%**

### 凯利公式参考

> **凯利比例 f = (p × b - q) / b**
>
> 其中 p = 获胜概率（乐观+基准=75%），q = 失败概率（25%），b = 赔率（42.2% / 17.4% = 2.43）
>
> **f = (0.75 × 2.43 - 0.25) / 2.43 = 0.647**
>
> **Half-Kelly（建议仓位）= 32.4%**

|--------|---------|
| EV ＞ 20% | 高赔率机会，强烈考虑 |
